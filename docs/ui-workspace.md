# Общая оболочка интерфейса Investbook

Обновлены главная, аналитика и оформление прикладных страниц. Один светлый фон, постоянное боковое меню, общий верхний блок и одинаковые таблицы/формы. Интерфейс рассчитан на настольный экран; адаптация для телефона не входит в эту работу.

## Как устроены переходы

- `templates/fragments/workspace.html` подключает общие локальные ресурсы к Thymeleaf-страницам. Три статические служебные HTML-страницы подключают те же ресурсы напрямую.
- `app-shell.js` создаёт оболочку и отмечает безопасные переходы чтения. Turbo Drive 8.0.20 заменяет содержимое страницы без новой вкладки и полного перезапуска документа. Боковое меню и шапка имеют `data-turbo-permanent`.
- Автоматический перехват всех ссылок, предзагрузка и перехват форм отключены. Изменение данных, загрузка отчётов, поиск POST, действия `/delete`/`update`, файлы и экспорт сохраняют обычное поведение браузера. У них остаётся та же вкладка; формы могут перезагружать документ.
- Старые страницы редактирования сохраняют свои формы и обработчики. Ссылки на руководство и генерируемый HTML/Excel-отчёт открываются обычным переходом; оформление экспортируемых документов не меняется.
- События `investbook:page-load` / `investbook:page-leave` управляют жизненным циклом графиков и обновлением обзора. При уходе графики уничтожаются, запросы отменяются, таймеры очищаются. Модуль состава общий для обоих видов круговой диаграммы.
- Встроенные стили отдельных страниц и CSS обзора помечены `data-turbo-track="dynamic"`, чтобы стили не переходили в соседние разделы. Сохранение снимков страниц выключено для финансовых данных и canvas-графиков.

## Фильтры и данные

Счета и даты аналитики сохраняются в `sessionStorage` текущей вкладки и в URL графиков. Явные параметры URL имеют приоритет. Вкладки «Стоимость и рост», «По бумагам», «По секторам» переносят выбранные счета; период сохраняется при возврате к истории. Состав по-прежнему оценивается по последним доступным ценам — дата из истории не выдаётся за исторический состав.

На форме генерации отчёта восстанавливаются выбранные счета и период. Таблицы операций сохраняют собственные фильтры и серверный поиск. Обзор показывает активные счета и текущие известные оценки; исторический период графика не изменяет смысл этих сумм.

Отсутствие активных счетов больше не передаётся как пустой набор со значением «все счета» в legacy-расчёт диаграмм. Явный несуществующий или пустой набор отклоняется. Архивный счёт можно выбрать явно из списка существующих счетов.

На главной нет демонстрационных финансовых значений: при отсутствии данных показаны подсказки и загрузка первого отчёта. Данные, используемые браузерными тестами для графиков, подменяются только в тестовом браузере и не записываются в БД.

## Проверки

Java:

```bash
bash mvnw -Dtest=AnalyticsSelectionTest test
```

Полный прогон с ранее добавленным MCP:

```bash
export INVESTBOOK_MCP_PYTHON="$PWD/integrations/investbook-mcp/.venv/bin/python"
bash mvnw test
```

Проверено 226 Java-тестов: 219 успешных, 7 ранее отключены; ошибок нет. Включены 4 новых проверки выбора счетов и сквозной тест MCP.

Браузерная проверка требует работающий Investbook с отдельной пустой тестовой БД, Node.js, Chromium и Playwright. Она не отправляет формы изменения данных и не загружает демопортфель в БД.

```bash
npm ci --prefix src/test/ui
CHROMIUM_PATH=/usr/bin/chromium node src/test/ui/workspace.cjs
```

`INVESTBOOK_UI_URL` позволяет указать адрес тестового приложения; по умолчанию используется порт 2030 на loopback. Проверяются единый фон, постоянство оболочки, переходы, Back, обновление страницы, сохранение периода, корректная граница месяца, формы редактирования, статические настройки и отсутствие новых окон/ошибок JavaScript.

Для проверки настоящего рендеринга amCharts в изолированной среде загрузите неизменённые файлы с `https://cdn.amcharts.com/lib/` в отдельный временный каталог с сохранением путей:

- `5/index.js`, `5/xy.js`, `5/themes/Animated.js`;
- `4/core.js`, `4/charts.js`.

Затем передайте путь через `AMCHART_CACHE`:

```bash
AMCHART_CACHE=/absolute/path/to/amcharts node src/test/ui/workspace.cjs
```

Этот режим дополнительно строит линейные и круговую диаграммы на явно обозначенных демонстрационных данных, проверяет повторное создание и уничтожение графиков и делает скриншоты. Он прошёл в Chromium на экране 1440 × 1060. Скриншоты сохраняются вне репозитория в `/tmp/investbook-ui/`.

Turbo поставляется локально с лицензией и сведениями о версии в `static/vendor/README.md`. Для рабочих графиков сохраняется существующая зависимость от CDN amCharts; при ошибке загрузки интерфейс показывает сообщение. Постоянная навигация работает без CDN.
